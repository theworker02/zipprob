# zipprob

Zip timestamps and prob durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/zipprob/

## Install / run

```bash
git clone https://github.com/theworker02/zipprob.git
cd zipprob
node src/cli.js
node --test
```
